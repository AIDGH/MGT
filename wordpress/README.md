# نسخه مستقل وردپرس جهان تجارت مجد

این نسخه برای بررسی و تأیید است. سایت Next.js/NestJS، دیتابیس PostgreSQL، دامنه و سرویس‌های سرور اصلی تغییر نکرده‌اند.

## پیش‌نمایش محلی

```sh
cd /Users/arad/Documents/MGT/MGT/wordpress
npm ci
npm run preview
```

- سایت: http://127.0.0.1:9400/
- انگلیسی: http://127.0.0.1:9400/?lang=en
- محصولات: http://127.0.0.1:9400/products/
- مدیریت: http://127.0.0.1:9400/wp-admin/
- حساب مستقل پیش‌نمایش: فایل `.runtime/credentials.json`؛ رمز تصادفی است و در گیت ثبت نمی‌شود. این حساب با حساب سایت اصلی متفاوت است.

محیط توسعه از [WordPress Playground رسمی](https://developer.wordpress.org/playground/developers/local-development/wp-playground-cli/) با WordPress 7.1.3، PHP 8.3 و SQLite استفاده می‌کند. داده‌های آزمایشی داخل `.runtime/wordpress` باقی می‌مانند. پاک‌کردن این پوشه باعث حذف ویرایش‌های پیش‌نمایش می‌شود. برای اجرای ابزار، Node مطابق نیاز بسته Playground (۲۴٫۱۸ یا بالاتر) و curl لازم است. این وابستگی‌های Node فقط برای پیش‌نمایش هستند؛ هاست نهایی Node، NestJS یا PostgreSQL نیاز ندارد.

## ساختار

- `wp-content/themes/mgt-classic`: قالب PHP اختصاصی؛ همان CSS، فونت، تصاویر، لوگوها و اندازه‌های نسخه اصلی. صفحه اصلی، فهرست محصولات با جست‌وجو و دسته‌بندی، جزئیات و گالری محصول، صفحه ۴۰۴.
- `wp-content/plugins/mgt-content`: مدل‌های محتوای محصولات و اسلایدها، دسته‌های دو زبانه، انتخاب تصویر از کتابخانه رسانه وردپرس و تنظیمات متن‌ها و تماس. داده‌ها با تعویض قالب از بین نمی‌روند.
- `source`: تصویر لحظه‌ای محتوای عمومی سایت اصلی؛ شامل داده‌های ورود یا رمز نیست.
- `tools/import-content.php`: ورود یک‌باره محتوا و رسانه از خروجی قبلی؛ اجرای دوباره موارد واردشده و ویرایش‌های محلی را بازنویسی نمی‌کند.

داده‌های فارسی و انگلیسی در یک محصول/اسلاید نگهداری می‌شوند. `?lang=en` نمای انگلیسی را فعال می‌کند و لینک‌های داخلی زبان را حفظ می‌کنند. بدون پارامتر، سایت فارسی است. اسلایدر از لمس، کلیدهای جهت، توقف و کاهش حرکت پشتیبانی می‌کند. تلفن‌ها قابل تماس و اطلاعات تماس قابل کپی هستند.

## ویرایش در پنل

1. **محصولات ← افزودن محصول**: نام‌ها، شماره قطعه، توضیحات و مشخصات دو زبان، گالری و دسته را وارد کنید. نام فارسی با عنوان وردپرس هماهنگ می‌شود. نشانی محصول را از قسمت پیوند یکتا تعیین کنید.
2. وضعیت «منتشرشده» در سایت دیده می‌شود؛ «پیش‌نویس» و «زباله‌دان» عمومی نیستند. برای خارج کردن محصول از نمایش، آن را به پیش‌نویس برگردانید.
3. **محصولات ← دسته‌بندی محصولات**: نام فارسی و انگلیسی دسته را وارد کنید.
4. **اسلایدر**: متن‌ها، تصویر و لینک هر اسلاید را ویرایش کنید. ترتیب از «ویژگی‌ها ← ترتیب» و فعال/غیرفعال از انتشار/پیش‌نویس مشخص می‌شود.
5. **محتوای سایت مجد**: متن درباره ما، پیام مدیرعامل و اطلاعات تماس در هر دو زبان.
6. **رسانه**: مدیریت و بارگذاری تصاویر؛ **کاربران ← شناسنامه**: تغییر رمز.

نیازی به قالب آماده، صفحه‌ساز، افزونه پولی یا ووکامرس نیست. این نسخه کاتالوگ و استعلام است، مطابق امکانات سایت فعلی.

## خروجی قابل نصب روی هاست وردپرس

```sh
npm run package
```

فایل‌های `dist/mgt-content.zip` و `dist/mgt-classic.zip` به‌ترتیب از قسمت افزونه‌ها و نمایش ← پوسته‌ها نصب می‌شوند. ابتدا افزونه و بعد قالب را فعال کنید. بسته‌ها شامل رمز، دیتابیس آزمایشی، ابزار Playground یا فایل‌های سایت Next.js نیستند.

برای هاست نهایی، وردپرس با PHP 8.3 و MySQL/MariaDB، HTTPS، قابلیت بازنویسی آدرس‌ها و پوشه uploads قابل نوشتن نیاز است. نصب روی MySQL/MariaDB هنوز در این نسخه محلی بررسی نشده است؛ کد قالب و افزونه از APIهای استاندارد وردپرس استفاده می‌کنند.

### ورود محتوا روی نصب تازه

پس از فعال‌کردن افزونه و قالب، پوشه‌های `source` و `tools` را خارج از پوشه عمومی وب قرار دهید و از WP-CLI استفاده کنید:

```sh
wp eval-file /private/path/wordpress/tools/import-content.php
```

اگر فایل‌های خروجی در محل دیگری‌اند، ثابت `MGT_IMPORT_DIR` را قبل از اجرای فایل تعریف کنید. ابزار ورود، تصاویر را از `source/media` وارد کتابخانه رسانه می‌کند؛ تصویر نمونه همراه قالب نیز پشتیبانی می‌شود. شکست ورود تصویر به‌صورت خطا گزارش می‌شود.

### قبل از جایگزینی سایت اصلی

این پیش‌نمایش از **محتوای عمومی منتشرشده** ساخته شده است. `node tools/export-public.mjs` خروجی تازه‌ای از تمام صفحات API عمومی و تصاویر می‌گیرد؛ روی سرور اصلی چیزی نمی‌نویسد. برای انتقال نهایی، باید پیش‌نویس‌ها، موارد بایگانی‌شده و تصاویر استفاده‌نشده نیز از دیتابیس اصلی به خروجی کامل اضافه و تطبیق داده شوند. حساب‌ها و سشن‌های NestJS به وردپرس منتقل نمی‌شوند؛ حساب‌های وردپرس جداگانه ساخته می‌شوند.

تغییر دامنه، ایمیل، DNS و جایگزینی سرویس فقط پس از تأیید کاربر و تهیه پشتیبان انجام می‌شود. پیش از آن باید نسخه هاست نهایی، لینک‌ها، ورود مدیریت و رسانه‌ها بررسی شوند. رکوردهای ایمیل دامنه نباید با انتقال وب تغییر کنند. سایت قبلی برای بازگشت نگه داشته می‌شود.
