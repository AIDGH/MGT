# Majd Global Trading

وب‌سایت دو‌زبانه شرکت، کاتالوگ محصولات و پنل مدیریت محتوا.

## ساختار

- Next.js / React: صفحه اصلی، `/products`، `/products/[slug]` و `/admin`
- Nest.js در `api/src`: ماژول‌های ورود مدیر، محصولات و دسته‌ها، محتوای سایت و تصاویر
- PostgreSQL + Prisma: اسکیما و migration در `api/prisma`
- فایل تصاویر: مسیر پایدار خارج از release؛ تنها JPG/PNG/WebP پذیرفته و به WebP تبدیل می‌شوند.

## اجرای محلی

Node.js 24 و PostgreSQL نیاز است. یک دیتابیس مخصوص این پروژه ایجاد کنید.

```sh
npm ci
cp api/.env.example api/.env
# DATABASE_URL را در api/.env تنظیم کنید.
set -a
source api/.env
set +a
npm run db:migrate
npm run seed -w api
npm run api:dev
# در ترمینال دوم، از ریشه پروژه:
npm run dev
```

وب روی 127.0.0.1:3001 و API روی 127.0.0.1:4001 اجرا می‌شود. Next.js درخواست‌های `/api` و `/uploads` را در محیط محلی به API هدایت می‌کند. حساب عمومی یا رمز ثابت در پروژه وجود ندارد.

## ساخت حساب مدیر

از ریشه، با DATABASE_URL تنظیم‌شده:

```sh
mkdir -p .secrets
ADMIN_USERNAME=admin ADMIN_CREDENTIAL_FILE="$PWD/.secrets/admin.txt" npm run admin:create -w api
```

رمز تصادفی فقط در فایل خصوصی با مجوز 600 نوشته می‌شود. حساب موجود بازنویسی نمی‌شود. ورود اول فقط اجازه تغییر رمز را می‌دهد؛ رمز جدید حداقل ۱۲ کاراکتر است. تغییر رمز همه نشست‌ها را باطل می‌کند. نشست‌ها هشت‌ساعته، در دیتابیس به‌صورت hash و در مرورگر با کوکی HttpOnly/Secure/SameSite ذخیره می‌شوند. نوشتن در API نیازمند Origin معتبر است و ورود محدودیت نرخ دارد.

## استفاده از پنل

- محصولات: عنوان دو زبان، نشانی انگلیسی یکتا، کد، دسته‌بندی، توضیحات، مشخصات و تا ۸ تصویر. تصویر اول، تصویر اصلی است.
- پیش‌نویس/بایگانی از API عمومی و صفحات سایت پنهان‌اند. انتشار حداقل یک عکس می‌خواهد. حذف محصول با بایگانی انجام می‌شود تا قابل بازگشت باشد.
- دسته‌بندی: افزودن و ویرایش نام دو زبان و نشانی.
- اسلایدر: تصویر، متن دو زبان، لینک داخلی، ترتیب عددی و فعال/غیرفعال. همه اسلایدها را می‌توان غیرفعال کرد.
- محتوا: متن‌های اصلی و درباره ما، پیام مدیرعامل و اطلاعات تماس در دو زبان. چیدمان ثابت است.
- کتابخانه تصاویر: بارگذاری و استفاده مجدد؛ حداکثر ۸ مگابایت/۲۵ مگاپیکسل، تبدیل به WebP و حذف metadata.
- ذخیره هم‌زمان از دو پنجره با version کنترل می‌شود تا ویرایش جدید به‌طور خاموش بازنویسی نشود.

فهرست پنل فعلاً تا ۱۰۰۰ محصول و ۲۰۰ تصویر اخیر را نمایش می‌دهد؛ صفحه عمومی محصولات صفحه‌بندی ۱۲تایی دارد. نسخه اول مدیریت دسترسی چندسطحی یا فروش آنلاین ندارد.

## انتشار روی سرور HostIran

نسخه‌های برنامه در `/opt/mgt/releases/<release>`، لینک فعال در `/opt/mgt/current`، اطلاعات اتصال در `/etc/mgt/api.env`، تصاویر در `/var/lib/mgt/uploads` و دیتابیس `mgt` هستند. API و وب با کاربر غیرریشه `mgt` و systemd اجرا می‌شوند. پورت‌های داخلی فقط به loopback گوش می‌دهند؛ Nginx ورودی HTTPS است.

اولین بار، پس از نصب Node.js 24 و PostgreSQL، `python3 ops/provision.py` را به‌عنوان root اجرا کنید. این اسکریپت حساب سرویس و دیتابیس اختصاصی می‌سازد و رمز اتصال را چاپ نمی‌کند. سپس سورس و lockfile را بدون `.env`، `.git`، `node_modules`، `.next` و `.secrets` به یک release جدید منتقل کنید و اجرا کنید:

```sh
bash /opt/mgt/releases/<release>/ops/deploy.sh <release>
```

ساخت و راه‌اندازی قبل از تغییر Nginx انجام می‌شود. نسخه ایستای قبلی در `/var/www/majdglobaltrading/current` حفظ شده است. تنظیم Nginx قبل از هر انتشار در `/etc/mgt/nginx-before-<release>.conf` ذخیره می‌شود. برای بازگشت برنامه، لینک `/opt/mgt/current` را به release قبلی برگردانید و دو سرویس را restart کنید. migrationهای ناسازگار در آینده به برنامه بازگشت جداگانه نیاز دارند.

## پشتیبان‌گیری

`mgt-backup.timer` روزانه ساعت ۰۲:۳۰ تهران دیتابیس و تصاویر را در `/var/backups/mgt` با نگهداری ۱۴ روز ذخیره می‌کند. بکاپ فعلی روی همین سرور است؛ برای محافظت در برابر ازبین‌رفتن کل سرور، مقصد جداگانه باید اضافه شود. بکاپ شامل داده حساس است و نباید عمومی شود.

برای بازیابی، سرویس API را متوقف کنید، از وضعیت فعلی بکاپ بگیرید، `database.dump` را با `pg_restore` به دیتابیس خالی برگردانید و `uploads.tar.gz` را در `/var/lib/mgt` استخراج کنید. مالکیت تصاویر باید `mgt:mgt` و دسترسی خواندن عمومی فایل‌ها برقرار باشد؛ سپس API را راه‌اندازی کنید.
