# Majd Global Trading

دموی دو‌زبانه و واکنش‌گرای سایت جهان تجارت مجد با Next.js و React.

## اجرای محلی

```sh
npm install
npm run dev
```

سایت در http://127.0.0.1:3001 در دسترس است.

## ساخت نسخه نهایی

```sh
npm run build
```

خروجی ایستا در پوشه `out` ساخته می‌شود و برای میزبانی ایستا آماده است. نسخه فعلی روی https://majdglobaltrading.com با Nginx و گواهی Let’s Encrypt منتشر شده است.

## ساختار

- `app/page.js`: صفحه اصلی، تغییر کامل زبان فارسی/انگلیسی، اسلایدر چهارتایی، جست‌وجوی دسته‌های نمونه، درباره ما و اطلاعات تماس
- `app/globals.css`: رنگ‌ها، فونت و چیدمان موبایل و دسکتاپ
- `public/brand`: لوگوهای استخراج‌شده از فایل‌های اصلی شرکت
- `public/fonts`: فونت محلی Vazirmatn، برگرفته از پروژه مرجع Hotel-Yab

لوگوهای فارسی و انگلیسی از `MGT.OfficeBoard.Persian.pdf` و نشان مستقل از `MGT.DeskFlag.Arabic.pdf` استخراج شده‌اند. هویت بصری از مجموعه سربرگ، کارت ویزیت و بسته‌بندی پوشه assets گرفته شده است. نشانی، ایمیل‌ها و شماره‌های تماس مطابق اطلاعات اعلام‌شده کاربر هستند. شماره‌ها لینک تماس و دکمه کپی دارند.

این نسخه معرفی شرکت است و دیتابیس، کاتالوگ واقعی و فرم ارسال پیام ندارد. جست‌وجو فعلاً چهار دسته نمایشی اسلایدر را پیدا می‌کند؛ هر چهار اسلاید از عکس نمونه ارسالی استفاده می‌کنند. لینک ایمیل‌ها برنامه ایمیل دستگاه را باز می‌کنند. متن معرفی اولیه برای بازبینی شرکت است.
